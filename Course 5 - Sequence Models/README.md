# Course 5 - Sequence Models

This repository contains all programming assignments, quizzes, and labs for **Course 5: Sequence Models**, part of the [Deep Learning Specialization](https://www.coursera.org/specializations/deep-learning) by DeepLearning.AI, taught by Andrew Ng.

## Course Overview

This course focuses on building and training sequence models, including Recurrent Neural Networks (RNNs), Gated Recurrent Units (GRUs), Long Short-Term Memory networks (LSTMs), and Transformers. You will apply these models to real-world tasks such as natural language processing, music generation, and speech-based trigger word detection.

## Weekly Breakdown

### Week 1 - Recurrent Neural Networks

You will implement:
- A character-level language model to generate dinosaur names.
- An LSTM model to generate jazz music.
- Basic RNN building blocks from scratch using NumPy.

**Folders:**
- `Building your Recurrent Neural Network - Step by Step`
- `Dinosaur Island - Character-Level Language Modeling`
- `Jazz Improvisation with LSTM`

You will:
