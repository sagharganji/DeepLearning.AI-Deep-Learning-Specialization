# Course 2: Improving Deep Neural Networks  
## Hyperparameter Tuning, Regularization and Optimization

This repository contains the full implementation of exercises and quizzes for **Course 2** of the [DeepLearning.AI Deep Learning Specialization](https://www.coursera.org/learn/deep-neural-network), taught by Andrew Ng.

The course focuses on practical techniques to improve the performance of deep neural networks, including initialization strategies, regularization, gradient checking, optimization algorithms, and an introduction to TensorFlow.

---
