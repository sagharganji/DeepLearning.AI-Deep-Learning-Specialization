# Course 3: Structuring Machine Learning Projects

This repository contains case studies and quizzes for **Course 3** of the [DeepLearning.AI Deep Learning Specialization](https://www.coursera.org/learn/machine-learning-projects), taught by Andrew Ng.

This course focuses on best practices and strategies for structuring machine learning projects in the real world. It provides insights into how to effectively design, execute, and improve ML pipelines by identifying common issues such as data mismatch, high variance, and label noise.

---

## Course Structure

### Week 1: ML Strategy - Part 1
- Topics:
  - Orthogonalization and ML system design
  - Establishing evaluation metrics
  - Single-number evaluation metrics and satisficing metrics
  - Error analysis and manual error checking
  - Case study: Bird recognition in Peacetopia

- Included:
  - `Week 1 Quiz - Bird recognition in the city of Peacetopia (case study).pdf`

---

### Week 2: ML Strategy - Part 2
- Topics:
  - Mismatch between training and dev/test data
  - Strategies for handling data mismatch
  - End-to-end deep learning vs. pipeline approaches
  - Transfer learning and multitask learning
  - Case study: Autonomous driving project

- Included:
  - `Week 2 Quiz - Autonomous driving (case study).pdf`

---

## Key Takeaways
- Apply error analysis and bias-variance strategies to real-world cases
- Prioritize the right tasks to reduce model error effectively
- Understand how to deal with train/dev/test mismatches
- Use appropriate metrics to guide project direction
- Learn how to make informed trade-offs in ML design decisions
