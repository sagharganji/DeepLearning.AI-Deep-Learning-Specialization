# Course 1: Neural Networks and Deep Learning

This repository contains all exercises, quizzes, and notes from **Course 1** of the [DeepLearning.AI Deep Learning Specialization](https://www.coursera.org/learn/neural-networks-deep-learning), taught by Andrew Ng on Coursera.

The course introduces the foundations of deep learning, including neural networks, forward/backward propagation, and the construction of deep learning models from scratch using Python and NumPy.
